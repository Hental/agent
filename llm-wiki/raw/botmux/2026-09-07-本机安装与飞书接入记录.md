## 继续接入

先检查已有配置；当前已经存在 `botmux-0`，不要重复创建应用：

```bash
botmux setup list --json
```

以下为本次使用的创建命令，保留用于复现；只有明确需要新建应用时才执行：

```bash
botmux setup add \
  --create-app \
  --allowed-users 'liutao.fe@bytedance.com' \
  --app-name 'Botmux Codex' \
  --cli codex \
  --cli-path /opt/homebrew/bin/codex \
  --backend tmux \
  --working-dir /Users/liutao/workspace \
  --default-working-dir /Users/liutao/workspace/agent
```

官方说明中，`--create-app` 默认在登录后继续创建应用、配置权限和长连接事件、设置 redirect 并发布版本。本次自动配置已完成：导入 280 项权限，跳过当前租户目录不存在的 19 项；redirect URL 为 `http://127.0.0.1:9768/callback`，已提交发布版本 `7682615425734560988`。

如果之后 setup 已保存机器人，但返回部分成功，应根据返回的 AppID 运行 `botmux setup configure <AppID>` 继续配置，避免再次新建应用。

本次已执行启动与检查；后续排查可使用：

