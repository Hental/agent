# 微信群语音呼叫

本目录保存 macOS AppleScript 工作流：打开最近聊天中的“退款”群，点击多人通话，只邀请“余生”，按本次指定次数提交呼叫，默认 1 次。已经存在通话窗口时拒绝再次拨号；识别到接听或无法确定的状态时停止，保留通话。

## 开发约定

- 本文件适用于 `apps/wx-call/`，同时遵循仓库根目录的 `AGENTS.md`。
- 修改文档、修复脚本和运行测试不代表获得实际拨号授权。仅在用户明确要求执行呼叫时，按指定群聊、成员和累计次数操作。
- 默认使用离线测试；不得用 `call` 或 `run` 验证计数、恢复逻辑或错误分支。
- 保留拨号前的群名、成员和按钮核对，以及已有通话检查、累计记录与互斥锁。读取失败必须中止，不能重置计数继续执行。
- 实测的界面尺寸、偏移和状态识别条件发生变化时，同步更新本文件；未验证的能力明确标注限制。
- 项目说明维护在本文件，不创建 `README.md`。截图、日志、编译缓存和测试临时目录统一放在仓库 `.reports/` 下。

## 文件和依赖

- `call.applescript`：流程、截图、成员核对、累计记录、等待和事件日志。
- `wx-call`：Bash 启动器，用 `osascript` 执行主脚本；编译缓存和运行锁都放在项目 `.reports/`。
- `vision.swift`：使用 macOS Vision 做本地 OCR，并识别当前版本通话窗口的等待动画。无需外部模型或 API 密钥。
- `check.py`：17 项离线计数回归测试，覆盖计数缺失、损坏、正常值、大累计值和无效执行次数；不接触微信界面。
- 依赖 macOS、已登录的桌面微信、Xcode Command Line Tools、`cliclick`（可通过 `brew install cliclick` 安装）。运行宿主需要已有的辅助功能、屏幕录制和 System Events 自动化权限。脚本不修改权限。

微信当前版本的聊天区域没有提供可点击的 AX 控件，所以 AppleScript 负责窗口和流程，`cliclick` 负责实际鼠标点击。它会操作真实桌面；运行时保持微信可见，避免同时操作鼠标或改变布局。

## 使用

在仓库根目录运行：

```bash
# 只准备成员选择，不发出呼叫；检查后点击“取消”才能再次运行。
apps/wx-call/wx-call prepare

# 发出一次呼叫后返回。
apps/wx-call/wx-call call

# 持续观察，并在上次仍为等待状态、随后窗口消失后继续下一次。
apps/wx-call/wx-call run

# 仅截图并报告通话状态。
apps/wx-call/wx-call status

# 离线读取累计记录，不接触微信。
apps/wx-call/wx-call budget
```

参数格式为 `wx-call <prepare|call|run|status|budget> [群名] [成员名] [本次次数]`，默认 `退款 余生 1`。本次次数须为正整数，不设 5 次上限；`run` 最多执行本次指定次数，`call` 仍只提交一次。累计记录不再阻止执行。已有通话、接通、未知状态等仍会提前停止。

默认报告目录为 `.reports/wx-call-YYYYMMDD/`。同一天的重复运行共用 `attempts.txt`，保留真实历史累计次数。接续特定任务时所有命令使用相同目录：

```bash
WX_CALL_REPORT_DIR="$PWD/.reports/wx-call-20260910" apps/wx-call/wx-call budget
```

提交前先增加累计记录。即使点击结果不明确，也不会自动退还次数。不要在恢复同一任务时删除计数文件或换目录。`prepare`、`status`、`budget` 不计数。`call` 和 `run` 共享互斥锁；异常退出留下锁时，先确认没有运行中的进程再移除 `.reports/wx-call-cache/active.lock/`。启动器在锁内用 Bash 内置检查与 noclobber 创建新任务计数，不覆盖已有文件。AppleScript 原生读取计数，任何读取失败（包括缺失）或损坏都会中止，绝不回退为 0。不再根据累计次数提前退出。

## 已验证的界面范围

- 本机中文微信，主窗口尺寸 **1019 × 790**，普通四人“退款”群；群名需出现在左侧最近聊天列表。
- OCR 在指定区域精确匹配群名、群标题、成员名、“选择成员”和“完成”。窗口位置可变，点击位置由窗口几何数据换算。
- 多人通话图标使用主窗口内已实测的偏移；成员弹窗应是刚打开、仅本人默认选中的状态。已有弹窗会中止，不重复切换勾选。
- 通话窗口 **600 × 487**，两名参与者。等待识别只针对本次余生头像中央的三点动画，不能作为任意联系人或其他版本的通用状态识别。

其他群人数、微信版本、窗口尺寸、搜索结果页、布局或遮挡可能需要重新校准。参数可修改名称，但不代表支持所有群。不要去掉核对步骤来绕过不匹配。

## 状态与限制

- `ringing`：观察到已校准的等待动画和“挂断”文字。
- `connected`：OCR 识别到明确的“对方已接听”或“通话中”。本次尚未获得真实接听样本，接通路径未完成实机验证。
- `unknown`：不能确定；立即停止自动重拨，保留窗口并供人工或 agent 查看截图。动画消失、头像显示或通话窗口出现本身都不作为接听成功。
- `ended`：语音通话窗口不存在；这本身不证明对方从未接听。
- `unanswered`：可见明确的未接听/拒绝提示；先保留界面供检查。

`run` 每次观察后等待约 1 秒，另有截图/OCR 耗时；最多观察 90 次，仍未结束则退出监控且不挂断。短于采样间隔的接听和结束可能漏检，不能保证捕获瞬时状态。两次拨号之间等待 10 秒。

脚本不会代替用户交谈，不录制音频、不发送聊天文字、不授予权限、不主动挂断。在本机实测时微信显示“无麦克风”，实际交谈需用户准备音频设备。

## 验证与维护

```bash
mkdir -p .reports/wx-call-cache
bash -n apps/wx-call/wx-call
python3 apps/wx-call/check.py
osacompile -o .reports/wx-call-cache/check.scpt apps/wx-call/call.applescript
xcrun swiftc apps/wx-call/vision.swift -o .reports/wx-call-cache/vision-check
```

用已捕获的等待、未知界面图片验证 OCR/状态识别，避免为测试额外拨号。实际拨号是外部通信，只在用户授权的对象、目的、次数范围内执行。截图、日志、编译产物和测试数据全部保存在 `.reports/`，不要提交聊天截图或联系人资料到源代码目录。
