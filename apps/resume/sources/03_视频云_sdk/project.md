# 火山引擎视频云 - 跨端 SDK 自动生成

## 项目结果与收益

- **业务落地：**2024 Q2 在直播 React Native SDK 应用，拉流覆盖 **69 个 API**、推流覆盖 **242 个 API**。
- **投入对比：**拉流实际投入 **13 人天**，人工方案预估 **45 人天**；推流实际投入 **19 人天**，人工方案预估 **50 人天**。将重复封装转为生成工具，实际投入低于人工方案预估，差额不视为实测节省值。

## 项目简介

时间：2024 Q2 落地

外部客户需要 React Native 等跨端 SDK。大量 API 封装重复、周期长，逐个手工适配的投入较高。

## 个人职责

建设 Native API 提取、结构化转换、TypeScript 代码生成和运行时调用链路，在直播 React Native SDK 场景落地。

## 技术介绍

- **API 提取：**基于 Doxygen 二次开发提取 Native API 信息，转换为结构化数据，作为跨端代码生成的统一输入。
- **代码生成：**按规则将结构化 API 转换为 TypeScript SDK 封装，减少逐个接口手工适配。
- **运行时调用：**通过 IPC 与 Native 反射衔接生成接口和底层能力，在直播 React Native SDK 中应用同一套生成链路。

## 证据与统计口径

口径：45 / 50 人天为非自动方案评估值，不是历史同项目实测；不将二者差值表述为已经测量的总节省人天。
