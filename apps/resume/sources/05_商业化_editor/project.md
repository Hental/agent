# 广告 - 移动端落地页编辑器

## 项目结果与收益

- **业务落地：**移动端落地页编辑器在 DOU+ 落地，广告主可基于模板完成编辑和投放，缩短从内容制作到可访问页面的操作链路。
- **项目规模：**原始项目记录管理模板 **300 余个**、日均有消耗站点 **87 个**、日均广告消耗 **1.7 万+**。这些数字体现平台承载规模；未据此推算个人新增营收或工时收益。

## 项目简介

时间：2020.10 — 2022.10

面向中小广告主建设移动端落地页编辑器，满足在 DOU+ 场景快速建站与投放的需求。通过模板二次编辑、资源管理与统一渲染，解决页面制作流程分散、重复开发与投放衔接的问题。

## 个人职责

完成移动端编辑器设计与开发，搭建模板管理后台，贯通组件资源、Node BFF 和页面渲染，在 DOU+ 落地。

## 技术介绍

- **模板与组件：**搭建模板管理后台，衔接组件资源，为广告主提供可复用的页面制作基础。
- **移动端编辑：**实现落地页编辑器，支持基于模板二次编辑，适配 DOU+ 建站场景。
- **发布与渲染：**通过 Node.js BFF 贯通编辑数据与落地页渲染，衔接页面制作、投放和用户访问。

## 证据与统计口径

口径：广告消耗是项目承载的投放规模，原材料未注明币种及精确统计窗口；不等同于个人创造的新增营收。
