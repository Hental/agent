# 生活服务 - 交易研发资产

## 项目结果与收益

- **场景复现：**串联真机画面、接口抓取、Mock、截图与测试商品，支持订单、提单和商详场景查找与复现，减少手工收集分散信息的步骤。
- **团队质量结果：**2026 Q2 资产准确率由 **81.81% 提升至 92.31%**，场景与 UI 覆盖率由 **38.71% 提升至 58%**。
- **实际采用：**同期内部试用覆盖 **18 个需求**，处理 **32 个问题**；个人贡献为截图采集及相关质量优化，收益未单独进行工时测量。

## 项目简介

时间：2025 — 2026

生活服务交易涉及多行业、多业务身份与大量 UI 场景。截图、接口、卡片和测试商品分散，开发者难以快速找到可用数据、复现页面和定位问题，因此建设统一的研发资产采集与场景复现能力。

## 个人职责

负责截图采集、运行时卡片标识、业务身份埋点关联、接口对接、预览及采集质量优化；协助 Oncall 接入。

## 技术介绍

- 集成任意门与真机画面同步，保存接口、截图和测试商品，支持后续场景复现。
- 卡片路由关系采集从 AST 反查调整为运行时标注，通过 dataset 获取真实卡片标识。
- 面向订单、提单、商详持续优化截图准确率、覆盖率和采集链路。

## 证据与统计口径

口径：均为 2026 Q2 团队复盘指标，平台仍处于内部试用；代码图谱、知识库和端到端字段分析由其他同事承担。任意门为集成能力。
