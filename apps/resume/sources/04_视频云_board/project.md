# 火山引擎视频云 - 互动白板

## 项目结果与收益

- **复用与交付：**实现一套核心代码三端共享，单需求 Native 人力投入由 **3 降至 0.5**，减少多端重复开发。
- **体验与可靠性：**端到端延迟由 **600ms 降至 100ms**；静态／动态转码最终成功率分别提升至 **99% / 98%**。
- **工程质量：**单元测试覆盖率由 **0 提升至 74%**，千行 Bug 率由 **30+ 降至 1 以下**；SDK 初始化代码由约 **100 行减少至 10 行以内**，降低接入成本。

## 项目简介

时间：2022.10 — 2024.03 主要建设期

面向在线教育、企业直播等实时协作场景建设互动白板，支持绘制、多人协同与录制回放。项目需要同时解决低延迟、状态一致性、多端重复开发及 SDK 边界状态难以人工覆盖的问题。

## 个人职责

负责整体技术设计和产品能力建设，主导移动端 SDK 跨端迁移，持续推进性能、转码可靠性、单元测试与客户接入。

## 技术介绍

- **协同与回放：**基于 Canvas 2D 绘制，使用实时信令与 Protobuf 传输消息，结合元素锁、一致性检测与快照机制支撑多人协作和录制回放。
- **跨端架构：**将移动端 SDK 从 Native 迁移至 WebView / Hybrid，设计通用实例与方法调用协议，复用核心代码并减少桥接层适配。
- **性能与质量：**优化消息传输、转码架构与重试机制；引入单元测试和 CI，并建设 20 余个数据看板支持问题定位。
