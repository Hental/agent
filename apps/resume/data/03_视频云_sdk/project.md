汇总计算依据：550 个 API 取自[年度总结](../../sources/00_公共资料/s34-platform-2024-summary.md)的四项计数；89／206 人天由上表工时相加，直播采用口径依据[用户确认 U14](user-confirmed.md)；约 57% 为本地计算值，不是来源原文直接给出的整体指标。原文定位分别见 sdk-06、sdk-07、sdk-08、sdk-12、sdk-13；直播原始明细另见[直播工时统计](../../sources/03_视频云_sdk/s24-sdk-live-effort.md)，未改写为采用后的口径。
