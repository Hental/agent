## 互动白板 · 项目简介 {#board.problem}

面向在线教育、企业直播等实时协作场景建设互动白板，支持绘制、多人协同与录制回放。项目需要同时解决低延迟、状态一致性、多端重复开发及 SDK 边界状态难以人工覆盖的问题。

## 互动白板 · 个人职责 {#board.responsibility}

负责整体技术设计和产品能力建设，主导移动端 SDK 跨端迁移，持续推进性能、转码可靠性、单元测试与客户接入。

## 互动白板 · 指标口径 {#board.scope}

口径：以上为原始述职中的项目结果；转码成功率排除用户文件原因。Native 投入原文为“人力/单需求”，不等同于人天。

## 互动白板 · 技术介绍 {#board.body}

- **协同与回放：**基于 Canvas 2D 绘制，使用实时信令与 Protobuf 传输消息，结合元素锁、一致性检测与快照机制支撑多人协作和录制回放。
- **跨端架构：**将移动端 SDK 从 Native 迁移至 WebView / Hybrid，设计通用实例与方法调用协议，复用核心代码并减少桥接层适配。
- **性能与质量：**优化消息传输、转码架构与重试机制；引入单元测试和 CI，并建设 20 余个数据看板支持问题定位。

## SDK 自动生成 · 项目简介 {#sdk.problem}

外部客户需要 React Native 等跨端 SDK。大量 API 封装重复、周期长，逐个手工适配的投入较高。

## SDK 自动生成 · 个人职责 {#sdk.responsibility}

建设 Native API 提取、结构化转换、TypeScript 代码生成和运行时调用链路，在直播 React Native SDK 场景落地。

## SDK 自动生成 · 指标口径 {#sdk.scope}

口径：45 / 50 人天为非自动方案评估值，不是历史同项目实测；不将二者差值表述为已经测量的总节省人天。

## SDK 自动生成 · 技术介绍 {#sdk.body}

- **API 提取：**基于 Doxygen 二次开发提取 Native API 信息，转换为结构化数据，作为跨端代码生成的统一输入。
- **代码生成：**按规则将结构化 API 转换为 TypeScript SDK 封装，减少逐个接口手工适配。
- **运行时调用：**通过 IPC 与 Native 反射衔接生成接口和底层能力，在直播 React Native SDK 中应用同一套生成链路。

## 订单 E2E 自动化 · 项目简介 {#e2e.problem}

2025 年订单域曾出现卡片／按钮缺失导致用户无法核销、退款的问题。围绕这些风险，按业务场景标识组织测试数据，在发布前自动复现页面并比较线上与预发布环境的 UI 差异，降低逐场景维护测试脚本的成本。见 [技术方案](#s15)。

## 订单 E2E 自动化 · 个人职责 {#e2e.responsibility}

承担前端订单回归能力建设，串联流量回放、接口模拟服务、真机执行与 界面差异检测，建设任务编排和 持续集成流水线任务节点并接入订单发布回归；持续治理截图噪音与执行异常，扩展多页面全链路回放。

## 订单 E2E 自动化 · 成果口径 {#e2e.scope}

口径：Q1 复盘记录业务场景标识数据覆盖度 100%，分母为订单页面埋点中的业务场景标识，不代表全部状态、交互路径或代码覆盖。同期单次执行完成率约 40%，多次重试后可达 95% 以上；95% 完成率及噪音率从 73% 降至 10% 是后续治理目标，不能写作已达成。产品平台与初始 界面差异检测 能力由 客户端团队提供，本人聚焦 前端串联、工程化和治理。见 [Q1 复盘](#s16)、[分工](#s15)。

## 订单 E2E 自动化 · 技术介绍 {#e2e.body}

- **真实数据驱动：**复用资产采集测试数据，按行业与业务场景标识准备回归任务，重建接口响应并写入接口模拟服务；解耦接口回放环境与 前端资源包环境，通过真机测试平台执行双环境真机截图。
- **执行与流程编排：**建设任务与子任务管理，以及回放、真机截图、差异检测、结果确认四阶段流程，封装 持续集成流水线任务节点和 定时任务，管理任务触发、进度、动态超时与终止清理。
- **差异与稳定性治理：**针对设备尺寸差异、白屏与状态栏噪音，完善截图有效性校验、白屏复检及 图像差异检测引擎降级；结合阈值自动放行与人工确认，上报执行成功率、噪音率和耗时。
- **全链路扩展：**通过 用户行为埋点日志关联商品详情页—订单提交页—订单，重建多页面响应并合并 Mock，支持完整性校验与页面级结果展示。见 [当前源码](#s13)、[原子节点](#s14)、[三仓改动](#s18)。
