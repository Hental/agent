## 职业摘要 {#overview.intro}

从商业化页面搭建，到实时协作与跨端 SDK，再到生活服务交易研发资产。职业主线是将复杂业务中的共性问题，转化为可复用的技术能力。

## 任职时间与岗位定位说明 {#overview.caption}

方向为材料归纳，非正式职级。入职时间为 2020 年 10 月；本次范围尚未满六周年。近期正文证据主要截至 2026 年 7 月初。

## 调岗日期说明 {#timeline.note}

* 2024 年调岗月份由交接和周报衔接推定，正式日期待本人确认。

## 简历定位 {#timeline.positioning}

**简历定位**：前端架构与研发效能方向。优先呈现架构取舍、复用设计、质量与交付结果；AI 经验以研发流程中的实际接入和应用为范围。

## 商业化阶段 {#timeline.1}

移动端落地页编辑器、模板管理、组件资源、Node BFF 与渲染链路，支持中小广告主在 DOU+ 完成建站和投放。

## 视频云阶段 {#timeline.2}

作为互动白板 Owner 推动实时协作、跨端复用和质量建设；进一步建设跨端 SDK 自动生成，并参与 WebRTC 解决方案。

## 生活服务阶段 {#timeline.3}

支持交易需求与卡片标准化，建设截图、接口和 Mock 资产采集，优化场景复现、资产质量及 Oncall 流程。

## 互动白板 · 业务问题 {#board.problem}

实时绘制与多人协同要求低延迟、状态一致；多端独立开发维护成本高，SDK 边界状态难以靠人工测试覆盖。

## 互动白板 · 个人职责 {#board.responsibility}

负责整体技术设计和产品能力建设，主导移动端 SDK 跨端迁移，持续推进性能、转码可靠性、单元测试与客户接入。

## 互动白板 · 指标口径 {#board.scope}

口径：以上为原始述职中的项目结果；转码成功率排除用户文件原因。Native 投入原文为“人力/单需求”，不等同于人天。

## 互动白板 · 技术工作与面试重点 {#board.body}

- 通用实例与方法调用协议降低桥接层适配成本，单需求 Native 人力投入由 **3 降至 0.5**。
- 通过传输链路、转码架构与重试机制优化，改善实时交互和资料展示体验。
- 引入单元测试与 CI，覆盖边界状态；建设 20 余个数据看板，支撑问题定位。

## SDK 自动生成 · 业务问题 {#sdk.problem}

外部客户需要 React Native 等跨端 SDK。大量 API 封装重复、周期长，逐个手工适配的投入较高。

## SDK 自动生成 · 个人职责 {#sdk.responsibility}

建设 Native API 提取、结构化转换、TypeScript 代码生成和运行时调用链路，在直播 React Native SDK 场景落地。

## SDK 自动生成 · 指标口径 {#sdk.scope}

口径：45 / 50 人天为非自动方案评估值，不是历史同项目实测；不将二者差值表述为已经测量的总节省人天。

## SDK 自动生成 · 技术工作与面试重点 {#sdk.body}

面试重点：API 信息如何归一化，类型、对象实例和回调如何跨语言传递，生成代码如何与 Native SDK 版本保持一致。

## 交易研发资产 · 业务问题 {#assets.problem}

多行业、多业务身份带来大量 UI 场景。截图、接口、卡片与测试商品分散，开发者难以快速复现和定位。

## 交易研发资产 · 个人职责 {#assets.responsibility}

负责截图采集、运行时卡片标识、业务身份埋点关联、接口对接、预览及采集质量优化；协助 Oncall 接入。

## 交易研发资产 · 指标口径 {#assets.scope}

口径：均为 2026 Q2 团队复盘指标，平台仍处于内部试用；代码图谱、知识库和端到端字段分析由其他同事承担。任意门为集成能力。

## 交易研发资产 · 技术工作与面试重点 {#assets.body}

- 集成任意门与真机画面同步，保存接口、截图和测试商品，支持后续场景复现。
- 卡片路由关系采集从 AST 反查调整为运行时标注，通过 dataset 获取真实卡片标识。
- 面向订单、提单、商详持续优化截图准确率、覆盖率和采集链路。

## 商业化编辑器 · 业务问题 {#editor.problem}

中小广告主需要便捷制作移动端落地页，使用模板完成二次编辑，并快速进入广告投放链路。

## 商业化编辑器 · 个人职责 {#editor.responsibility}

完成移动端编辑器设计与开发，搭建模板管理后台，贯通组件资源、Node BFF 和页面渲染，在 DOU+ 落地。

## 商业化编辑器 · 指标口径 {#editor.scope}

口径：广告消耗是项目承载的投放规模，原材料未注明币种及精确统计窗口；不等同于个人创造的新增营收。

## 未采用指标及原因 {#evidence.note1}

2025 年度总结中的“调试提效 80%”“30 分钟降到 5 分钟”缺少原始测量依据；白板 76 万分钟包含测试；Oncall 机器人“11 个样本、84.62%”的分母口径不清，因此未纳入核心成果。见 [年度总结](#s1)、[述职及评论](#s2)、[团队复盘](#s7)。

## 建设与采用情况 {#evidence.note2}

小程序 SDK 已完成建设，但后续交接没有客户使用，不能写商业化落地。2025 Q2 自动化基础链路已跑通，但未在实际卡片场景落地；2026 Q2 平台调整为内部试用。相关内容分别见 [交接](#s3)、[个人记录](#s11)、[团队复盘](#s7)。
